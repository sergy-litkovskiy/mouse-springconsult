# AGENTS.md

Спільні правила для агентів-рев'юерів цього репо. Файл читають Codex (OpenAI) і
Copilot (GitHub); Claude Code — через імпорт `@AGENTS.md` у кореневому `CLAUDE.md`.
Тримай правила короткими: що довший файл, то слабший сигнал.

## Project context

Внутрішня адмінка для підготовки карток комісійних товарів (Prom / OLX), один-два
адміни. Модульний моноліт: `apps/api` (Fastify, TypeORM, Postgres) і `apps/web`
(Angular). Кадри лежать у бакеті R2, публічному на читання; тексти генерує Claude
API, і кожен виклик коштує грошей. Домен публічний, тож недовіреними вважаються:
HTTP-ввід (body, query, params), завантажені файли, xlsx-експорт Prom і відповідь
моделі.

Шари, напрямок залежностей і конвенції — у `CLAUDE.md` (корінь, `apps/*`,
`apps/api/src/modules/*`). Зауваження до стилю звіряй з ними, а не з загальними
звичками.

## Review guidelines

Пріоритети знахідок:

- **P0 — блокує мердж.** Безпека й корупція даних: SQL/path injection, хардкоднуті
  секрети, недовірений ввід без zod-схеми в `*Controller.ts`, маршрут без
  `sessionGuard`, запис `descriptionProm` повз `cleanDescription`, ключ R2 з
  користувацького рядка; втрата даних, міграція без робочого `down`.
- **P1 — лагодимо перед мерджем.** Логічні баги, хибні межі, неопрацьовані
  крайні випадки, регресії, відсутні тести на нову поведінку, зворотна стрілка
  залежності між шарами чи deep import в чужий модуль.
- **P2 — на розсуд автора.** Дублювання, читабельність, дрібні ризики стилю.

Правила проходу:

- Кожна знахідка — з посиланням `file:line`, класом проблеми і конкретним фіксом.
- Параметризуй SQL. Ніколи не конкатенуй ввід у запит.
- Секрети — лише в `process.env` через `src/config.ts`; ніколи в коді й ніколи в
  `@environments` фронту.
- Рев'ю агента **доповнює**, а не **заміняє** детерміновані перевірки. CI вже
  проганяє format, lint, typecheck, `deps:check`, тести й up/down міграцій — те,
  що ловлять вони, не дублюй.
