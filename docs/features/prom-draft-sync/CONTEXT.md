# Domain Context — prom-draft-sync

Це дельта до [кореневого CONTEXT.md](../../../CONTEXT.md), а не копія. «Картка товару», «готова
картка» й «published-prom» визначено там. Тут лише те, що вводить ця фіча.

## Glossary

- **чернетка Prom** — товар, створений на Prom зі статусом «чернетка»: він є в кабінеті продавця, але покупці його не бачать. NOT published-prom: публікацію на вітрину робить user у кабінеті, і лише тоді товар стає published-prom.
- **синхронізація з Prom** — одноразове створення чернетки Prom з готової нової картки натисканням кнопки. NOT двостороння синхронізація: зміни з кабінету назад в адмінку не повертаються, а вже створений на Prom товар кнопка не оновлює.
- **розділ маркетплейсу** — рубрика каталогу Prom, обов'язкова для товару; Prom пропонує її автоматично, а user обирає в кабінеті. NOT група магазину (власна, необов'язкова структура сайту продавця) і NOT колишнє поле «Категорія» адмінки.
