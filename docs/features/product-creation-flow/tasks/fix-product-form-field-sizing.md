# T41 — Висота поля ціни й мітки у формі картки

## Context

Запит 2026-09-17, UI-доопрацювання до поставки 2. У діалозі картки поле «Ціна, ₴» помітно
вище за сусідні «Категорія» і «Стан» у тому самому рядку. Крім того, усі мітки й
плейсхолдери форми мають стати дрібнішими й світлосірими, як у фільтрах.

**Імовірна причина висоти.** Поля стоять у `.card-form__row` (`display: flex`, типове
`align-items: stretch`). Лише ціна має `subscriptSizing="dynamic"`, тобто не резервує місця
під підказку. Сусідні поля мають фіксований резерв близько 22 px. Stretch витягує ціну до
їхньої повної висоти разом із резервом, і рамка поля росте. У панелі фільтрів цього не
видно, бо там уже стоїть `align-items: flex-start`
([T37](resize-catalog-filter-fields.md)). Гіпотезу перевірити на екрані до правки.
`subscriptSizing="dynamic"` лишається, бо без нього довгий текст помилки ціни обрізається.

**Мітки.** Спільний стиль задає [T40](compact-catalog-filter-fields.md) у `styles.css`.
Тут треба лише перевірити, що форма його успадкувала, зокрема `textarea` описів і
`mat-select` «Стан». Окремих правил для форми додавати не слід, хіба що якесь поле стиль
не підхопить.

## API contract excerpt

Поля форми — властивості `Product`; задача змінює їхній вигляд, а не склад:

```yaml
    Product:
        titleProm: { type: string, maxLength: 200 }
        descriptionProm: { type: string, maxLength: 8000 }
        titleOlx: { type: string, maxLength: 200 }
        descriptionOlx: { type: string, maxLength: 8000 }
```

## Acceptance criteria

**AC-38 (нове) — happy path**
**Given** `user` відкрив діалог картки на екрані шириною 1280 px
**When** форма відмальована
**Then** рамки полів «Ціна, ₴», «Категорія» і «Стан» мають однакову висоту (різниця ≤ 1 px), а всі мітки й плейсхолдери форми дрібніші й світлосірі, поки поле порожнє й без фокусу

**AC-38 — edge case**
**Given** у ціну введено `12.345`
**When** під полем з'явилась помилка «Ціна виглядає як 2499 або 2499.00.»
**Then** рамка ціни лишається тієї самої висоти, що й сусідні, а текст помилки видно повністю, без обрізання

## Checklist

3. Перевірити, що мітки й плейсхолдери форми, зокрема `textarea` і `mat-select`, успадкували стиль T40. Якщо якесь поле його не підхопило, додати точкове правило.
4. `pw`: знімок діалогу на 1280 і 360 px, з хибною ціною і без неї, додати до PR.
5. `PRD.md §5`: AC-38 з посиланням на цю story.
