# T59 — Ключові слова як chips

## Context

Запит 2026-09-21, пункт 4. Ключові слова зараз — один `input` через кому
(`product-form.html`, «Ключові слова»). Рядок з 20–30 слів не видно цілком, окреме слово важко
знайти, виправити чи прибрати. Власник просить окремі chips: кожне слово можна відредагувати
чи видалити, нове додається введенням, а поле росте в висоту разом зі списком.

**Що змінюється в коді форми.**

- Контрол `seoKeywords` стає `string[]` замість рядка. Зникають `parseKeywords` і
  `join(', ')` у `fill()`; спільне перетворення «картка → значення поля» (`product-form.ts`,
  з рефактору T55) для ключових слів повертає масив, а не рядок. Звірка T55 у `reread()`
  порівнює масиви за значенням, а не за посиланням — інакше вона вважатиме поле зміненим.
- Чернетка для `scope: field` (`draft()`) лишається рядком: `draftText` у контракті — рядок,
  тож масив з'єднується через кому лише там.
- Валідатор `keywordsBound` переписується під масив. Межі з контракту не змінюються: кожне
  слово 1–60 символів, понад 30 слів — не помилка, сервер обрізає (AC-07), а підказка це каже.

**Компонент.** `mat-chip-grid` + `mat-chip-row` з `editable` і кнопкою видалення +
`input` з `matChipInputFor` і `matChipInputTokenEnd`. Роздільники — `Enter` і кома; вставка
рядка з комами розбивається на кілька chips. Порожні й повторні слова не додаються. Chips у
`apps/web` ще не використовувались, тож ця задача вводить патерн і його тести, на які спирається
[T62](pick-catalog-categories-with-autocomplete.md).

## Sequence

> `user->>web: вписує обидва заголовки, описи, ключові слова й ціну`
> `api->>api: лишає перші 30 ключових слів, решту відкидає (AC-07)`

Послідовність зі [sad.md §6](../sad.md#6-runtime-view), сценарій 6, не змінюється: межу 30
тримає `api`, форма лише показує слова окремо.

## Data delta

**Немає.** `seoKeywords` у контракті вже масив рядків; змінюється лише подання у формі.

## API contract excerpt

```yaml
        seoKeywords:
          type: array
          maxItems: 30
          items: { type: string, maxLength: 60 }
          description: Понад тридцять — не помилка; зайве обрізається (AC-07).
```

## Acceptance criteria

Нове AC із запиту 2026-09-21; до [PRD §5](../PRD.md#5-acceptance-criteria) його вносить
крок 6 чекліста. Межі — [AC-07](../PRD.md#5-acceptance-criteria), вони не змінюються.

**AC-53 (нове) — happy path**
**Given** відкрита картка з ключовими словами
**When** `user` додає слово (Enter чи кома), редагує наявне подвійним кліком і видаляє інше хрестиком
**Then** кожне слово — окремий chip, поле росте в висоту зі списком, а «Зберегти» надсилає `seoKeywords` масивом у тому порядку, що на екрані

**AC-53 — edge case**
**Given** `user` вставляє рядок `"миша, миша, , logitech"` або вводить слово довше за 60 символів
**When** значення потрапляє в поле
**Then** додаються лише `миша` і `logitech` без порожніх і повторів, а задовге слово показує помилку довжини й блокує «Зберегти», як раніше

**AC-53 — domain invariant**
**Given** «Згенерувати все» завершилось, і `api` застосував ключові слова сам (AC-05, T55)
**When** форма перечитала картку
**Then** chips показують нові слова без кліку, а слова, які `user` правив під час запуску, лишаються його (AC-11)

## Checklist

1. `product-form.spec.ts`: тести через `MatChipGridHarness` на додавання, редагування, видалення, вставку з комами й повторами, помилку довжини; наявні тести T55 (AC-05/AC-11) переписати на масив і лишити зеленими.
2. `product-form.ts`: контрол `seoKeywords: string[]`, валідатор під масив, прибрати `parseKeywords`, перетворення картки на поле й звірка T55 — масивом; `draft()` з'єднує масив через кому для `draftText`.
3. `product-form.html`: `mat-chip-grid` з `mat-chip-row` (`editable`, `matChipRemove`) і `input` з `matChipInputFor`; підказка про межу 30 лишається.
4. `product-form.css`: поле росте з вмістом, chips переносяться; на 360 px без горизонтального скролу.
5. Прийняття пропозиції `seoKeywords` («<- AI») кладе в контрол масив.
6. `PRD.md §5`: AC-53 з посиланням на цю story.
7. `pw`: додати, відредагувати й видалити слово, зберегти, `GET` картки повертає той самий масив.
