# T20 — Підфіча `products/form/` — форма картки

## Context

Екран, на якому виконується US-06: `user` вписує обидва заголовки, обидва описи, ключові
слова й ціну — і зберігає. Ручний шлях не має власного маршруту в API: він пише в ті самі
поля тим самим запитом, що й прийняття пропозиції, і саме тому AC-12 виконується сам собою.

**Уточнення 2026-09-12 (мокап картки, `docs/assets/add-edit-product-feature.pdf`).** Картка
відкривається як `MatDialog` (той самий компонент для створення й редагування), а не
маршрутом: заголовок «Картка товару», дії «Скасувати»/«Зберегти» знизу. Секція галереї
([T21](add-gallery-upload-dialog.md)) рендериться нагорі цього ж діалогу — не окремим
попапом. Доки в галереї немає жодного кадру, усі текстові й boolean поля та кнопки
«Generate all»/«Зберегти» недоступні (AC-20); щойно завантажено перший кадр — розблоковані.

Нова підфіча — вкладений каталог усередині `products/`, поряд із `catalog/` і `gallery/`
([apps/web/CLAUDE.md](../../../../apps/web/CLAUDE.md), правило 15).

## Sequence

[sad.md §6](../sad.md#6-runtime-view), **сценарій 6** — увесь шлях форми, включно з гілкою помилки:

> `user->>web: вписує обидва заголовки, описи, ключові слова й ціну`
> `alt формат ціни не проходить`
> `  web-->>user: показує, якою має бути ціна, а введене лишається у формі`
> `else картка приймається`
> `  web-->>user: збережено — шлях той самий, що й у підготовленої моделлю (AC-12)`

## Data delta

**Немає.** Форма пише через API. Два поля, які вона показує, колонок не мають зовсім:
`isReady` — предикат ([ADR 0009](../adr/0009-derive-card-readiness-instead-of-storing-it.md)),
`discardedKeywordsCount` — рахунок сервісу (AC-07). Обидва треба показати як похідні, а не
як стан, який форма може змінити.

## API contract excerpt

```yaml
      summary: Зберегти картку (заголовки, тексти, ключові слова, ціна, відмітки)
      description: >-
        Один маршрут для ручного шляху (US-06, AC-12) і для правки AI-підготовленого
      operationId: updateProduct
```

## Acceptance criteria

**AC-12** (US-06) — happy path
**Given** `user` не запускав жодної підготовки
**When** `user` вписує обидва описи, ключові слова й ціну сам і зберігає картку
**Then** система приймає картку так само, як і підготовлену з допомогою AI

**AC-13** (US-07) — domain invariant
**Given** картка має відмітку published-prom
**When** `user` відмічає, що товар зʼявився на OLX
**Then** обидві відмітки ведуться окремо, і зняття однієї не змінює другу

**AC-19** (US-01) — happy path
**Given** у галереї картки ще немає жодного кадру
**When** `user` завантажує перший кадр
**Then** цей кадр автоматично стає головним (виконує [T14](add-image-upload-endpoint.md); форма лише відображає результат)

**AC-20** (US-01, US-06) — domain invariant
**Given** у галереї картки немає жодного кадру
**When** `user` відкриває картку на створення чи редагування
**Then** усі текстові й boolean поля, кнопка «Generate all» і кнопка «Зберегти» недоступні для взаємодії; вони розблоковуються, щойно завантажено від одного до десяти кадрів

## Checklist

1. `products/form/product-form.ts` / `.html` / `.css` / `.spec.ts`.
2. `product-form` — `MatDialog`, відкривається з каталогу ([T22](integrate-catalog-with-form-and-delete.md)) через `MatDialog.open()`, той самий компонент для створення й редагування; дії «Скасувати» (`mat-dialog-close`) і «Зберегти» знизу.
3. Композиція: секція `gallery/` ([T21](add-gallery-upload-dialog.md)) нагорі шаблону — вбудований компонент, не окремий `MatDialog.open()`.
4. Форма через `FormBuilder`; стан валідації віддається в шаблон **сигналом** — zoneless форму не відстежує.
5. Ціна: маска й повідомлення за `pricePattern`; при відмові сервера введене лишається у формі (AC-09).
6. Ключові слова: після збереження показати `discardedKeywordsCount` (AC-07).
7. Дві відмітки присутності — незалежні перемикачі (AC-13).
8. Похідна готовність — показ, а не дія: перемикача «позначити готовою» немає.
9. Сигнал «є хоча б один кадр» (з кількості кадрів галереї) вимикає/вмикає текстові й boolean поля, «Generate all» і «Зберегти» (AC-20).
10. `app.routes.ts` цю підфічу не чіпає — картка не має власного маршруту (мокап 2026-09-12).

## Out of scope

- Логіка вивантаження, головного кадру й видалення всередині секції галереї — [T21](add-gallery-upload-dialog.md).
- Панель підготовки й пропозицій, кнопки «? -> AI»/«<- AI» — поставка 2, [T32](add-preparation-ui.md).
- WYSIWYG: тексти редагуються в `textarea` як plain text.
