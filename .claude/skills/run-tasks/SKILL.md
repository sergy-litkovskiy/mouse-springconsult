# /run-tasks — задачі за планом

Запусти реалізацію задач з @docs/features/product-creation-flow/tasks/tracker.md згідно плану
@docs/features/product-creation-flow/execution-plan.md.

Аргументи: `$ARGUMENTS`

## 1. Які задачі

- **Є аргументи.** Розбий за комою: від 1 до 5 ID. Кирилична `Т` дорівнює латинській `T`,
  регістр і пробіли не важать, голе число — теж ID (`62` = `T62`). Більше п'яти ID, повтор
  чи ID, якого немає в tracker, — STOP з поясненням, нічого не запускаючи.
- **Аргументів немає.** Візьми першу згори задачу таблиці «Що лишилось» у плані, яка в
  tracker має статус `Todo`, а всі її `blocked_by` — `Done`. Назви її одним рядком і починай.

Кожна задача пакета мусить мати рядок у таблиці плану, бо без нього немає Кроку А. Її
статус — `Todo` або `Blocked`, а кожна з `blocked_by` — `Done` або стоїть раніше в цьому ж
пакеті. Інакше (`Done`, `Deferred`, `In review`, незакрита залежність поза пакетом) — STOP
до початку роботи.

Виконуй за колонкою `#` плану, а не в порядку аргументів.

Якщо доріжка плану ставить поза пакетом відкриту задачу раніше за задачу з пакета, назви
її в першому повідомленні. Це не зупинка, бо пакет обрала людина. Але такі задачі правлять
ті самі файли, тож пропущена потім ребейзиться на пакет.

## 2. Кожна задача

Рядок плану — інструкція: Крок А за позначкою, «Між» — до Кроку Б, «Після» — після нього.
Гілку, коміти, push і PR веде `CLAUDE.md`. Push і PR робляться один раз, у кінці задачі,
після «Після», як у схемі плану: проміжного push заради draft після RED чи GREEN немає.

- `goal` — `/goal` запускає людина. Задачу ведеш сам і перевіряєш її умову `/goal` з плану
  дослівно.
- Платний виклик моделі в `pw` — лише з дозволу, із сумою до й після.

**Гілки — стеком.** Перша відходить від `origin/main`, кожна наступна — від гілки
попередньої задачі пакета, усі з `--no-track`. У кожної задачі свій PR у `main`. У тілі PR
задачі, що стоїть на іншій, назви PR попередньої й попроси мерджити їх по черзі звичайним
merge, не squash. Base на гілку попередньої не став: `delete_branch_on_merge` вимкнено, тож
GitHub сам не перемкне його на `main`.

Задача впала — STOP: наступні не починай, бо вони стоять на її гілці.
